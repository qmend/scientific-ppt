# Licensing and release notes

The project code is offered under MIT. The repository owner may choose another license before publication; MIT is a practical permissive default for this reusable Skill.

The supplied reference PPT files, textbook content, logos and embedded images remain owned by their respective rights holders. Only extracted style observations and aggregate measurements are included in versioned references. Converted source decks and full reference previews are Git-ignored. A style analysis does not grant redistribution rights to source materials.

The demo charts are generated from synthetic data by `scripts/make_demo.py`. No scientific findings are claimed and no source-deck images are reused. Commercial system fonts are not copied into the repository.

Python dependencies retain their own licenses, including their transitive dependencies. Review the metadata of the locked versions before redistribution. Notable components include python-pptx, Pillow, jsonschema, fonttools, latex2mathml, Ziamath/Ziafont, resvg-py, pypdf and pypdfium2. PDFium carries its own bundled third-party notices; preserve those when redistributing its binaries. Ziamath bundles STIX math font resources under their font license.

PowerPoint and LibreOffice are optional separately installed applications and are not distributed by this project. The project does not bypass activation or licensing. No paid/evaluation rendering service is bundled.
