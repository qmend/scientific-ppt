# Agent内容规划协议

先确定听众、要回答的问题与来源，再选择叙事结构；不按固定学科顺序填模板。

1. 建立来源清单：每个结论来自哪里、哪一页/表/图、日期、单位、是否为假设。保留争议和不确定性。涉及论文时读取方法、实验设置和限制，而非只读摘要。
2. 每页明确一个解释任务，例如问题、比较、方法、机制、结果、限制或后续工作。按任务选择图、文或表；不要为了装饰制造图表。
3. 使用`source`给内容块标注引用，完整引用写入notes。所有页面均把出处和章节/页码定位放入 PowerPoint 备注，不另建可见的底部来源行；参考文献页仍列完整文献。输入是主题时，由Agent补充可信来源或明确写为演示/假设，不由执行器生成事实。
4. 表格以字符串保存每个原始单元格，保留精度、单位、空值符号，设置唯一行ID。组是连续行的逻辑标签。禁止用四舍五入数据替换原始值。
5. 科研图片默认contain；只有装饰图且用户可接受裁切时指定`fit: cover`及`allow_crop: true`。即使允许，超过token裁切比例仍回退contain。
6. 图示先列出真实对象及关系，区分前向、反馈、共享输入和比较关系。系统介绍优先规划一幅可供汇报人完整讲解的全幅大图。用行列对齐和紧凑连线组织图形，用贴合内容的外框圈出阶段，保留具体的数据形态。用箭头类型标明不同关系。重新排布后实际尺寸仍不可读时，保留系统总图并增设局部详图。简单流程可使用原生节点边模型，复杂方法用 Drawlib 定制组合。见[科研图设计](figure_tools.md)。
7. 先用24pt正文预算排版。不能放下则改变图文分配、拆分解释任务，保留所有必须覆盖的材料。文字自动分页是最后一道保障；不要把一篇论文全文堆入一个text块当作叙事规划。
8. 输出前将内容覆盖清单与JSON逐项对应。检查是否重复说明、缺少重要实验条件、图意不清。全幅系统图可以靠图形、必要标签和图注支撑口头讲解，不强配侧栏正文；进一步讲述可放备注。页数是结果，不是压缩内容的硬约束，除非用户另有明确要求。
9. 以话题分割页面，A话题尾页有留白也不填入B话题。每个源slide代表独立解释任务，执行器不会把下个源slide拼入当前页。表格使用专用页，解释放在前后同话题页。跨页表格的非末页填满正文区，末页使用自然行高。续页只重复表头。
10. 首页和尾页复用固定首尾页配置：基本信息为汇报人、指导教师、日期，尾页为 THE END 与敬请指正，文献独立成页。可安排1至2页分段、首行缩进的叙述，避免全部页面都套图文分栏或浅色框。中文叙述页按[密度与出处规则](style_guide.md#中文叙述页密度与出处)规划约75%–80%的正文区占位感，用同话题的具体解释充实内容，段落紧凑向上排列；不靠拉大段距填满。常规出处写入备注，不生成底部“来源……”文本块。
11. 不把跨页表格作为默认展示任务。中等数据量的精确查数用表格，大量数据的趋势、分布与对比用数据图；小样本不强行扩展为大图。保持数据真实，按问题选择图型与面积。
12. 按[成品文案规范](style_guide.md#成品文案与单页强调色)完成交付文案检查。正文和图内直接呈现研究内容。AI、工具或制作过程说明写入对应页的 `notes`，导出到 PowerPoint 演讲者备注。保留必要的数据来源与模拟条件。每页关键词强调只选一种颜色，通常章节内沿用。

`plan`只处理标题和段落，适合已有提纲；`extract`只提取文本层。它们没有模型、检索、OCR、科学图理解或自动摘要能力。这些工作由调用Skill的Agent完成。
