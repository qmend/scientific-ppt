# 渲染、修复与验收

实际渲染只指PPTX被PowerPoint或LibreOffice打开后导出PDF，再由PDFium生成PNG。使用Python重新绘制场景不是实际PPT渲染，不能用来签署视觉验收。

默认auto优先PowerPoint，失败则尝试LibreOffice。每个后端运行在有超时的子进程中，不无限等待；失败原因进入报告。不使用Aspose试用水印图作为验收证据。Office进程异常退出时可能需要用户检查其后台实例，不终止用户其他文档。

## 自动检查

- 内容安全区、文本预测高度、内容块重叠、节点重叠、contain图片比例、页面占用率。
- PowerPoint后端进一步测量TextRange实际BoundHeight/BoundWidth，包含原生表格单元格。
- 渲染页数与PPTX页数相等、逐页非空检测。LibreOffice没有Office COM文字测量，因此仅依靠预测测量和人工视觉复核。
- 图片、图表内的文字没有OCR识别；曲线含义、箭头语义、缺失字形和审美质量不由自动检查保证。

正文溢出时提高测量安全系数并重排，标题可有限调整字号；正文和表格不缩字。自动修复默认最多2次，硬上限5次。每次尝试保存PPTX、预览和历史记录。不可修复的几何问题保留报告，不输出虚假全通过。

状态含义：

- `failed`：输入、资源或不可容纳内容错误，qa_report包含原因。
- `unverified`：已生成PPTX但没有实际渲染。
- `needs_review`：实际检查仍存在错误。
- `rendered_needs_visual_review`：渲染成功且无自动错误，仍需Agent视觉审阅。

`--strict`在未渲染或存在自动错误时退出码2。它不证明人工视觉验收已完成。`previews/index.json`是有效预览清单；目录中旧运行多出的PNG不得当作新结果。

## Agent审阅

首尾页对照[固定样式](bookends.md)，检查首页三行“汇报人、指导教师、日期”和尾页“THE END / 敬请指正”，以及居中英文页眉、细线、无页码。对并列要点页检查原生项目符号是否实际出现、同页符号是否一致、换行是否悬挂对齐；加粗小标题本身不算项目符号。连续叙述和图表页不要求套列表。

先看联系表检查风格节奏，再逐页看完整PNG。对照参考标题带、背景、字体层级、图内字号、页脚，检查图片图注距离、公式是否完整、表格行是否连续和线条是否可辨。报告每轮实质修复，最后记录输入和PPTX哈希。结构错误优先处理；如果正文太密，修改内容规划而不是把字变小。

同时检查正文、图内嵌字、图注和页脚的成品文案。AI 辅助和制作过程说明应出现在导出的 PowerPoint 演讲者备注中。所有页面均不显示底部独立“来源……”行或制作注释，逐页出处及章节/页码定位须保留在 PowerPoint 备注，完整文献集中在独立参考文献页；必要的模拟条件和直接引语引用按内容保留。清理未授权占位符和重复解释。逐页核对普通强调词、正文小标题和图内重点是否统一使用一种强调色。图内文字需检查实际渲染。

中文叙述页另外按[密度与出处规则](style_guide.md#中文叙述页密度与出处)检查：正文向上连续排列，紧凑正文块通常覆盖可用内容区约75%–80%的高度；不把空文本框或拉大的段间距算作内容占用。过空时先补充有依据的同话题解释或重分配段落，再渲染复查。话题尾页可保留合理留白，不能混入新话题。此项由 Agent 视觉审阅，现有自动占用率指标不等同于叙述密度达标。

## 单图验收

在入稿前先渲染单图，按论文最终栏宽或 PPT 投影尺寸检查实际标签大小、线宽和图例。兼顾两种用途时，分别检查两个尺寸下的效果。

- **对齐与图幅：** 核对并列分组外缘、标题基线、同阶段节点和主要端口。用一致的间距表现同类关系。确认长图按最终宽度缩放后仍可读。独立长图页检查图与图注整体是否在正文区上下居中，图注是否贴近图片，页脚上方是否有明显偏重的空白。
- **完整性与密度：** 系统图能追踪从输入到结果的主路径，来源中的必要分支和汇合没有因拆成小图而消失。检查是否存在大片无意义的空卡片、过宽通道，或单纯放大几个节点的伪大图；以规整结构提高有效信息密度，不凭空添边。
- **走线：** 逐条检查端口、箭头尖端、整段路径和边标签，包括曲线中段。文字与图标均需避让；弧线没有不必要的远绕，交叉与汇合可区分。先移动标签或端口、微调节点，再调整曲线；不要一遇到障碍就绕画布外缘。
- **箭头与阶段：** 按投影尺寸检查细箭头的平直端部、三角尖端和折点。核对虚线间隙、空心轮廓和彩色实心填充是否可辨，且与图例一致。检查同图分组外框是否统一为彩色实线或虚线，彩色实线是否比内部节点边框更明显，同级边缘和标题是否对齐。省略不必要且无法对齐的框。箭头从正确位置穿框并避开标题，同类圆角矩形的角弧一致。检查画布上方和框内是否有可收紧的空带。
- **文字与图例：** 图内标签常规字重，没有重复图注或重复解释；图例位置与整图视觉重心协调，符号和数据颜色对应。图标用于识别对象或数据流，风格一致。
- **数据图：** 样本量与面积相称，刻度、单位、观测点和色标正确；浅色系列在白底上仍可辨，多系列不只依赖颜色。图例不遮数据，并留出实际排版空间。

保存预览和简短检查结论，未解决的遮挡需明确列出。当前自动 QA 不识别外部 SVG/PNG 内的文字与曲线，也不提供 Drawlib 自动避障布线；以上检查由 Agent 看实际图执行，不能把“规范已更新”或“导出成功”当作图件已通过视觉验收。
